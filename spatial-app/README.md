# 空间数据分析应用（泛克里金 · 空间块验证 · 屏障 · 自适应加点）

从零散采样点推算区域连续曲面。核心原则：**相邻点随机拆分验证会高估精度** —
— 因此协方差参数只由训练块估计，验证一律按连续空间块划分，同批次的重复
采样永远保持在同一折。纯 Python + 原生前端，无需在线地图。

## 快速开始

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/make_sample_data.py   # 重新生成虚构示例数据（可选）
.venv/bin/python run.py                        # http://127.0.0.1:5050
.venv/bin/python -m pytest tests/ -q           # 17 个核对测试
```

## 功能与对应实现

| 需求 | 实现 |
|---|---|
| 带趋势项的空间插值 | 泛克里金：坐标线性趋势 + 地形协变量（GLS + 残差 GP），输出栅格均值与误差（标准差） |
| 协方差参数由训练块估计 | 每折只在训练块上做剖面 REML（`geostat/estimation.py`），全量拟合与逐折估计走同一入口 |
| 连续空间块验证 | k-means 空间块 / 网页手画矩形块；附随机拆分对照，直观展示精度高估 |
| 同批采样不拆分 | 划分单元是"批次质心"，同批测点必属同一块（`geostat/blocks.py`，有测试） |
| 重复/近重合/病态分别处理 | 精确重复→合并（块金 ÷ 测量次数）；近重合→合并或微扰（可选）；病态→逐级对角加噪。三类各出报告，说明改变了什么（`geostat/preprocessing.py`） |
| 遮挡边界阻断相关 | 屏障多边形 → 可见性图测地距离（点-点）与网格图距离（点-格）；相关沿绕障路径衰减，不跨边界平滑；接区域边界的墙可完全隔离（距离 inf → 相关 0） |
| 无支持区域标记 | 与所有测点最大相关 < 阈值（默认 0.05）的格点以 45° 纹理标出；屏障内部格点单独标为阻断 |
| 加点建议 | 序贯贪心：候选点评分 = 总方差精确下降 / 费用（基础费 + 行进费×到最近测点的测地距离），克里金方差不依赖观测值，无需假设取值 |
| 网页交互 | 画验证块、切换相关模型（指数/高斯/Matérn-3/2/球状）、点选预测格查看邻点权重（正蓝负红、线宽∝|w|）、接受建议后补入合成测量（条件模拟抽样）并重拟合 |
| 已知场核对 | `tests/test_known_field.py`：参数恢复、95% 区间覆盖率、标准化误差；`tests/test_barrier.py`：绕障距离、相关阻断、无支持标记 |
| 版本 | 每次拟合存模型版本（参数/配置/预处理报告/数据哈希），每次预测存栅格版本，`versions/` 落盘，网页可回读切换 |

## 数据格式

CSV（逗号分隔，含表头）：

```csv
id,x,y,value,batch,elev,moisture
p000,14.9,44.8,6.65,survey_A,51.1,0.67
```

- `x,y`：平面坐标（任意投影，单位自定）
- `value`：观测值；`batch`：采样批次（验证划分不拆同批）
- 其余列一律视为地形协变量，参与趋势项
- `data/barriers.json`：`{"domain": [x0,y0,x1,y1], "polygons": [[[x,y],...], ...]}`

## 方法要点

- **模型**：`y = Fβ + ε`，`Cov(ε) = sill·ρ(h; range) + nugget·I`；ρ 可选
  指数/高斯/Matérn-3/2/球状，统一以"实用变程"（相关降至 0.05）参数化。
- **估计**：剖面 REML，网格粗搜 + 有界 L-BFGS-B 细化；合并测点的块金为
  `nugget/测量次数`。
- **预测**：均值与方差为标准泛克里金公式；`target=field`（潜场，用于栅格）
  与 `target=measurement`（新测量，用于验证覆盖）分开。
- **屏障**：点-点用精确可见性图最短路；点-格用网格 8 邻接图多源
  Dijkstra。测地距离下的协方差不保证严格正定 —— 由预处理的条件数检查
  与对角加噪兜底，并在报告中明示。
- **验证**：块 CV 的每折重新估计参数（防泄漏）；区间覆盖率按
  `target=measurement` 计算。随机拆分对照组会明显显得"更准"，即高估。

## API 摘要

```
GET  /api/state            数据集、屏障、配置、版本
POST /api/fit              拟合（可带 config），返回参数+预处理报告+模型版本
POST /api/predict          生成栅格 {nx,ny} → 均值/标准差/无支持/阻断 + 栅格版本
POST /api/cv               {scheme:block|random, n_folds} 或 {rects:[[x0,y0,x1,y1]..]}
GET  /api/weights?x=&y=    预测格的邻点权重（top-12）与权重和
POST /api/suggest          {n, base_cost, travel_cost} → 排序候选点
POST /api/accept           {x,y} → 合成测量入库并重拟合
POST /api/upload           {csv} 替换数据集
GET  /api/versions         版本列表；POST /api/activate_grid 回读栅格版本
```

## 已知限制

- 栅格趋势外推时协变量取训练均值（未提供协变量栅格输入）；坐标趋势不受影响。
- 测地距离协方差的正定性靠加噪保证（有报告）；完全隔离区域的相关为 0。
- 加点建议为序贯贪心，非全局最优。
